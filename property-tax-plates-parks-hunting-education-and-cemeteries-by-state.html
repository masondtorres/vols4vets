Property Tax, Plates, Parks, Hunting, Education and Cemeteries by State

This Vols4Vets.com page keeps current links, phone numbers and source notes for the book chapter.

Official-source caution: Vols4Vets.com is a routing companion to the book. Official agencies, crisis lines, providers and program pages control action, eligibility, deadlines, phone numbers and forms.

Who this helps

Veteran, retiree, survivor, state benefit helper.

Best first step

Use the website ledger for current state rows. In print, use the method and the official parent source.

What to gather

DD214, state residency proof, rating letter if relevant, vehicle or property papers and school records.

Safety notes

  • Do not assume a property tax break, hunting license discount or park pass works the same way in every state.
  • Do not assume military, veteran, retiree, spouse and dependent all qualify the same way.
  • Do not apply using a form from another state. Use the current form from your own state's agency.
